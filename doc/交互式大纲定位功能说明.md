# 交互式大纲定位功能说明

## 功能概述

当AI生成大纲或列表时，你可以直接点击大纲中的任意项目，系统会自动在文档中定位到对应的内容并高亮显示。

## 功能特点

### 1. 智能识别大纲格式
系统自动识别以下格式的大纲：
- `1. 标题` - 数字编号
- `- 标题` - 短横线
- `• 标题` - 圆点符号
- `  - 子标题` - 缩进的子项

### 2. 可点击的大纲项
- 鼠标悬停时显示高亮效果
- 点击后自动在文档中搜索并定位
- 支持主项和子项的点击

### 3. 智能定位
- 在文档中搜索对应文本
- 自动选中匹配的文本
- 平滑滚动到可见区域
- 文本居中显示

## 使用方法

### 步骤1：生成大纲
1. 在AI助手中输入："生成文档大纲"
2. 或点击快捷指令"生成大纲"
3. AI会返回结构化的大纲

### 步骤2：点击定位
1. 在AI回复中，找到你想定位的大纲项
2. 鼠标悬停，项目会高亮显示
3. 点击该项目
4. 系统自动在文档中定位并高亮对应内容

### 步骤3：查看结果
- 文档编辑器自动滚动到对应位置
- 匹配的文本被选中（高亮）
- 显示"已定位到: XXX"的提示

## 技术实现

### 前端实现
1. **大纲识别**：正则表达式匹配大纲格式
2. **可点击元素**：为每个大纲项添加点击事件
3. **文本搜索**：在TipTap文档中搜索匹配文本
4. **位置定位**：计算文本位置并滚动
5. **文本选中**：使用TipTap的setTextSelection API

### 搜索算法
- 不区分大小写
- 支持部分匹配
- 优先匹配完整词组
- 自动去除标点符号

## 注意事项

### 1. 文本匹配
- 搜索不区分大小写
- 如果文档中有多个匹配，定位到第一个
- 如果文本不存在，显示"未找到"提示

### 2. 大纲格式
- AI生成的大纲需要符合标准格式
- 支持的格式：`1.`、`-`、`•`
- 子项需要有缩进（2个或更多空格）

### 3. 性能考虑
- 大文档搜索可能需要几毫秒
- 滚动动画使用平滑过渡
- 不影响编辑器性能

### 4. 兼容性
- 需要现代浏览器支持
- 依赖TipTap编辑器API
- 支持触摸设备点击

## 快捷操作

### 键盘快捷键（建议）
- `Ctrl+F` - 打开文档搜索
- `Esc` - 取消选中

### 鼠标操作
- **单击** - 定位到对应位置
- **悬停** - 预览可点击项
- **双击** - 选中整个大纲项（复制用）

## 常见问题

### Q1: 点击后没有反应？
A: 检查以下几点：
- 文档中是否存在对应文本
- 大纲格式是否正确
- 是否在AI助手的消息中点击

### Q2: 定位不准确？
A: 可能原因：
- 文档中有多个相似文本
- 文本格式不完全匹配
- 建议使用更具体的关键词

### Q3: 如何定位到第二个匹配项？
A: 当前版本定位到第一个匹配项。如需定位其他位置，可以：
- 使用更具体的文本
- 或使用编辑器的查找功能（Ctrl+F）

### Q4: 支持哪些大纲格式？
A: 支持以下格式：
- 数字编号：`1.`、`2.`、`3.`
- 短横线：`-`
- 圆点：`•`
- 缩进子项：`  -`、`  •`

### Q5: 可以自定义大纲样式吗？
A: 可以通过修改CSS来自定义：
- 悬停颜色
- 点击效果
- 字体大小
- 间距等
