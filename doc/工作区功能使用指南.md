# 工作区功能使用指南

## 功能概述

工作区功能允许用户在左侧面板中管理多个文档，实现：
- 多文档管理和快速切换
- 从AI回复创建新文档
- 自动保存和状态跟踪
- 文档重命名和删除

## 主要功能

### 1. 工作区面板

#### 位置
- 左侧边栏，与素材面板共享空间
- 通过顶部Tab切换"工作区"和"素材"

#### 功能
- **文档列表**：显示当前项目的所有文档
- **创建文档**：点击右上角"+"按钮
- **切换文档**：点击文档名称
- **重命名文档**：悬停显示编辑按钮，或双击文档名
- **删除文档**：悬停显示删除按钮

#### 文档信息显示
- 文档名称
- 字数统计
- 最后更新时间
- 未保存标记（橙色圆点）

### 2. 文档管理

#### 创建新文档
1. 点击工作区面板右上角的"+"按钮
2. 系统自动创建"未命名文档"
3. 编辑器切换到新文档
4. 可以立即开始编辑

#### 切换文档
1. 在工作区面板点击任意文档
2. 当前文档自动保存
3. 编辑器加载选中的文档内容

#### 重命名文档
**方法1：使用编辑按钮**
1. 悬停在文档上
2. 点击出现的"编辑"图标
3. 输入新名称
4. 按Enter或点击外部完成

**方法2：双击（如果实现）**
1. 双击文档名称
2. 直接编辑
3. 按Enter完成

#### 删除文档
1. 悬停在文档上
2. 点击"删除"图标
3. 确认删除
4. 如果删除的是当前文档，自动切换到其他文档

### 3. AI回复处理

当AI回复消息后，有两种处理方式：

#### 方式1：插入到当前文档
1. 点击AI消息下方的"插入文档"按钮
2. 内容插入到当前光标位置
3. 可以继续编辑

#### 方式2：另存为新文档 ⭐
1. 点击AI消息下方的"另存为新文档"按钮
2. 系统自动创建新文档
3. AI回复内容保存到新文档
4. 文档名称自动从内容前20个字符生成
5. 新文档出现在工作区列表中

### 4. 自动保存

#### 自动保存时机
- **定时保存**：每30秒自动保存当前文档
- **切换文档**：切换到其他文档时自动保存
- **返回项目列表**：返回时自动保存
- **关闭应用**：关闭前自动保存

#### 保存状态指示
- **已保存**：文档名称正常显示
- **未保存**：文档右上角显示橙色圆点

### 5. 数据存储

#### 存储位置
- 所有文档数据保存在浏览器的localStorage中
- 按项目ID隔离，不同项目的文档互不影响

#### 存储格式
```javascript
{
  id: "doc_1234567890_abc",
  name: "文档名称",
  content: { /* TipTap JSON格式 */ },
  wordCount: 1234,
  createdAt: "2026-02-08T10:00:00.000Z",
  updatedAt: "2026-02-08T10:30:00.000Z",
  hasUnsavedChanges: false
}
```

#### 存储限制
- localStorage通常有5-10MB的限制
- 如果空间不足，系统自动清理旧文档
- 保留最近的20个文档

## 使用场景

### 场景1：多文档写作
```
用户：正在写一本书，包含多个章节
操作：
1. 为每个章节创建一个文档
2. 命名为"第1章"、"第2章"等
3. 在不同章节间快速切换
4. 所有内容自动保存
```

```
用户：使用AI生成多个版本的内容

3. 再次请求："生成另一个版本"
4. 再次另存为新文档
5. 在工作区中对比不同版本
6. 选择最佳版本继续编辑
```

```
用户：收集和整理各种素材

1. 创建"灵感"文档
2. 创建"参考资料"文档
3. 创建"草稿"文档
4. 将AI生成的内容分类保存
5. 需要时快速查找和引用
```

### 场景4：项目协作准备
```
用户：准备多个相关文档
操作：
1. 创建"项目计划"文档
2. 创建"需求文档"文档
3. 创建"技术方案"文档
4. 在工作区中统一管理
5. 导出时一次性处理
```

## 快捷操作

### 键盘快捷键（建议）
- `Ctrl+N`：创建新文档
- `Ctrl+Tab`：切换到下一个文档
- `Ctrl+Shift+Tab`：切换到上一个文档
- `Ctrl+S`：手动保存当前文档
- `F2`：重命名当前文档

### 鼠标操作
- **单击文档**：切换文档
- **悬停文档**：显示操作按钮
- **点击编辑图标**：重命名
- **点击删除图标**：删除

## 注意事项

### 1. 数据安全
- ⚠️ 数据保存在浏览器localStorage中
- ⚠️ 清除浏览器数据会丢失所有文档
- ✅ 建议定期导出重要文档到本地文件
- ✅ 使用浏览器的"不清除特定网站数据"功能

### 2. 性能考虑
- 单个项目建议不超过50个文档
- 单个文档建议不超过10万字
- 超大文档可能影响加载速度

### 3. 浏览器兼容性
- 需要支持localStorage的现代浏览器
- Chrome、Firefox、Edge、Safari均支持
- IE浏览器不支持

### 4. 文档命名
- 文档名称不能重复
- 建议使用有意义的名称
- 避免使用特殊字符

## 常见问题

### Q1: 文档会自动保存吗？
A: 是的，系统每30秒自动保存，切换文档时也会自动保存。

### Q2: 可以恢复删除的文档吗？
A: 目前不支持恢复，删除前请确认。建议使用快照功能备份重要内容。

### Q3: 文档数量有限制吗？
A: 理论上没有限制，但受localStorage容量限制。空间不足时会自动清理旧文档。

### Q4: 可以在不同项目间复制文档吗？
A: 目前不支持，每个项目的文档是独立的。

### Q5: 如何导出所有文档？
A: 目前需要逐个导出。未来版本会添加批量导出功能。

### Q6: AI生成的文档名称可以修改吗？
A: 可以，创建后可以随时重命名。

### Q7: 切换文档时会丢失未保存的内容吗？
A: 不会，切换前会自动保存当前文档。

### Q8: 可以搜索文档内容吗？
A: 目前不支持全文搜索，未来版本会添加。
