# 文档导入功能说明

## 功能概述

文档导入功能允许用户将外部文档（Word、PDF、Markdown、纯文本）导入到编辑器中,自动转换为TipTap格式。

## 支持的格式

- **Word文档**: `.docx`, `.doc`
- **PDF文档**: `.pdf`
- **Markdown**: `.md`, `.markdown`
- **纯文本**: `.txt`, `.text`

## 使用方法

### 1. 点击导入按钮

在顶部工具栏中,点击"导入"按钮(Upload图标)。

### 2. 选择文件

在弹出的文件选择对话框中,选择要导入的文档文件。

### 3. 自动导入

系统会自动:
- 上传文件到后端
- 解析文档内容
- 转换为TipTap JSON格式
- 加载到编辑器中
- 保存为新的工作区文档

### 4. 查看结果

导入成功后:
- 文档内容会显示在编辑器中
- 自动创建一个新的工作区文档(使用原文件名)
- 显示成功提示

## 技术实现

### 前端

**文件**: `frontend/src/services/document-import.js`

主要函数:
- `parseDocument(file)` - 上传并解析文档
- `importDocument(file, onProgress)` - 完整导入流程
- `htmlToTipTapJSON(html)` - HTML转TipTap格式
- `textToTipTapJSON(text)` - 文本转TipTap格式

**文件**: `frontend/src/App.vue`

- `handleImportDocument()` - 处理导入操作
- 创建文件选择input
- 调用导入服务
- 更新编辑器和工作区

**文件**: `frontend/src/components/TopBar.vue`

- 添加"导入"按钮
- 触发`import-document`事件

### 后端

**文件**: `backend/services/document_parser.py`

解析器类:
- `WordParser` - 解析Word文档(.docx)
- `PDFParser` - 解析PDF文档
- `MarkdownParser` - 解析Markdown文档
- `TextParser` - 解析纯文本文档

**文件**: `backend/routes/document.py`

API端点:
- `POST /api/document/parse` - 解析上传的文档
- `GET /api/document/supported-formats` - 获取支持的格式

## 解析细节

### Word文档 (.docx)

- 提取段落和标题
- 保留标题层级(H1-H6)
- 提取表格内容
- 提取元数据(标题、作者、创建时间等)
- 转换为HTML格式

### PDF文档

- 逐页提取文本
- 保留页码信息
- 提取元数据(标题、作者、页数等)
- 简单的HTML转换

### Markdown文档

- 使用markdown库转换为HTML
- 支持YAML front matter元数据
- 保留Markdown格式

### 纯文本

- 自动检测编码(UTF-8, GBK, GB2312, Latin-1)
- 按行分段
- 简单的HTML转换

## 数据流程

```
用户选择文件
    ↓
前端: 创建FormData上传
    ↓
后端: 保存到临时目录
    ↓
后端: 调用对应的解析器
    ↓
后端: 返回文本内容和HTML
    ↓
前端: 转换为TipTap JSON
    ↓
前端: 加载到编辑器
    ↓
前端: 保存到工作区
```

## 错误处理

- 文件格式不支持 → 显示错误提示
- 解析失败 → 显示具体错误信息
- 网络错误 → 显示上传失败提示
- 空文档 → 显示"文档内容为空"

## 依赖库

### Python后端

```bash
pip install python-docx PyPDF2 markdown
```

已包含在`backend/requirements.txt`中。

### 前端

无需额外依赖,使用原生JavaScript和已有的TipTap库。

## 注意事项

1. **文件大小限制**: 建议不超过10MB
2. **格式兼容性**: 
   - Word: 仅支持.docx格式(不支持旧的.doc格式)
   - PDF: 仅提取文本,不保留格式和图片
3. **编码问题**: 纯文本文件会自动尝试多种编码
4. **临时文件**: 后端会自动清理上传的临时文件
